# 手工织锦纹样排版台

直接打开`index.html`使用。支持网格绘制、对称绘制、色线统计、撤销重做、本地保存和导出JSON。

## 功能

- 对称绘制：可选关闭 / 左右对称 / 上下对称 / 四向对称，镜像同步落色；越界忽略，中轴上的格子只画一次。
- 一次拖动合为一笔，撤销/重做按整笔回退；快速拖动自动补齐中间漏掉的格子。
- 切换对称方式或调整行列数时已画内容保留，后续笔迹按新中轴计算。
- 对称状态随方案保存和 JSON 导出，重开页面可继续绘制。

## 代码结构

- `state.js`：画布状态——网格数据、笔画归并、撤销重做、本地持久化。
- `symmetry.js`：对称规则——镜像落点计算、越界过滤、中轴去重。
- `app.js`：页面——DOM 渲染与交互，把状态和规则接到界面上。
