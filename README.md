# 手工织锦纹样排版台

直接打开`index.html`使用。支持网格绘制、对称绘制（左右 / 上下 / 四向）、色线统计、撤销重做（一次拖动记为一笔）、本地保存和导入导出 JSON。

- 对称方式可随时切换，已画内容保留，后续笔迹按新中轴计算；镜像越界忽略，中轴重复位置只画一次。
- 「调整尺寸」修改行列数时保留已画内容，「新建网格」则清空重开。
- 对称状态随保存和 JSON 导出一起记录，重开页面或导入文件后可继续画。

## 文件结构

- `index.html`：页面结构与样式
- `js/symmetry.js`：对称规则（镜像落点计算，越界忽略、中轴去重）
- `js/canvas-state.js`：画布状态（格子数据、笔画合并、撤销重做、尺寸调整、序列化）
- `js/app.js`：页面交互（渲染、色板、统计、预览、断线提示、保存与导入导出）
